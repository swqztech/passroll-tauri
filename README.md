# 随密 (Passroll, Tauri)

Random password / username / nickname generator. Rust clipboard, no console window.

## Develop

```bash
npm install
npm run dev
```

## Release

```bash
npm run build:client
```

Installer: `src-tauri/target/release/bundle/nsis/随密_1.0.0_x64-setup.exe` (name may vary by locale).

Launch: `Launch-Passroll.cmd`
